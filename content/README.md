# content ディレクトリ

サイトに表示する**本文コンテンツの元原稿（正本）**を置く場所。
画像などのメディアは `assets/`、開発者向けドキュメントは `docs/` に置く（役割を分ける）。

## 運用ルール（重要）

このサイトはビルドツールなしの静的サイトのため、**Markdown はそのままではブラウザに表示されない**。
ここに置く `.md` は「編集・改訂用の正本」であり、表示は `index.html` が担う。

```
content/*.md（正本・編集はこちら）  ──反映──▶  index.html（実際に表示される）
```

- 文章を直したいときは、まず該当の `.md` を編集する。
- 編集後、その内容を `index.html` の該当箇所へ反映する（反映作業は Claude Code に依頼すればよい）。
- `.md` と `index.html` の内容が食い違わないよう、必ずセットで更新する。

## ファイル

- `利用規約.md` … 利用規約の本文（正本）。※現状は下書き。要確認箇所は `【要記入】` で示している。
- `news.js` … お知らせ（News）の正本。**こちらは例外で、`index.html` への手動反映は不要**。
  `index.html` が起動時に読み込み、一覧を自動生成する（`.md` のような手作業のミラーは発生しない）。
  編集後はブラウザを再読み込みするだけ。編集は次の2通り:
  - **エディタ（推奨）**: `tools/news-editor.html` をブラウザで開き、フォームで追加・修正・並べ替え・削除
    → 「news.js を書き出す」でこのファイルの中身を生成 → 貼り付け／ダウンロードで置き換えてコミット。
    （このページは既定では保存・送信をしない“中身を作るだけの道具”。公開サイトには載らない）
    → 任意で「GitHub に直接保存」も可能（Fine-grained トークンを入力すると `content/news.js` へ直接コミット。
      トークンの保存はオプトイン。詳細はページ内の説明を参照）
  - **直接編集**: `news.js` を開き、ファイル冒頭コメントの手順どおり `{ ... }` ブロックを編集。
