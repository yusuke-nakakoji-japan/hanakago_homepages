## ディレクトリ視点でのまとめ

- **`assets/images/logo/`** … ロゴ（favicon・ヘッダー・モバイルメニュー・ヒーローの4箇所で共用）
- **`assets/images/hero/`** … ヒーローのメインビジュアル
- **`assets/images/menu/`** … メニューセクションの料理写真
- **`assets/images/dog/`** … ドッグランセクションの写真
- **`assets/images/gallery/`** … ギャラリーの写真（ライトボックス対応・連番）
- **`assets/patterns/`** … 背景装飾の和柄SVG3種（籠目＝コンセプト / 麻の葉＝CTA / 青海波＝フッター）
- **`assets/icons/`** … 現在は空。将来 favicon 専用画像や apple-touch-icon を追加する場所（※現状の favicon はロゴを流用中）

## 注意点

- **アクセス・お知らせ**セクションは現在画像未使用。お知らせに画像を添える場合は `assets/images/news/` を新設するのが規則に沿った形。
- **ロゴは4箇所で共用**。`assets/images/logo/logo.png` を差し替えると、favicon・ヘッダー・モバイルメニュー・ヒーローの表示がすべて一括で変わる。

## メニューの上限について

メニューカルーセルは **3つが上限ではなく、増減できる**（JS は項目数を動的に数えるため、コード改修は不要）。
`index.html` の `#menu` セクションで、以下の2箇所を項目数だけ増やす：

1. `<ul id="menuTrack">` 内に `<li class="hk-menu__item" data-idx="N">` ブロックを追加（写真は `assets/images/menu/` に `m4.jpeg` 等で追加）
2. `<div id="menuDots">` 内に対応する `<button class="hk-menu__dot" data-idx="N">` を1つ追加

`data-idx` は 0 から始まる連番で、`<li>` と `<button>` の並び順に一致させること。
