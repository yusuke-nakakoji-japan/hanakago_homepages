## カフェ セクション導入文の見直し（2026-07-25 起票 / 反映済み文の改善・案提示済み）

対象: `index.html` `hk-menu__copy`（カフェ導入のリード文）。
現行文（反映済み）:
> 地元野菜メインのお食事・甘味・お飲みものを、ごゆっくりお楽しみください。

※すでに反映・公開済み。緊急の不具合ではなく、より正確・上質にする任意の改善。

### 問題点

- [ ] **A｜係りの曖昧さ（意味のズレ）**
  「地元野菜メインの」が後続3語（お食事・甘味・お飲みもの）全体にかかると読め、甘味や飲み物まで地元野菜が主役、という不正確な意味になりうる。本来の意図は「お食事が地元野菜中心」のはず。係り先を明確にする。
- [ ] **B｜トーン・表記の不調和**
  「メイン」というカタカナ口語が、和カフェの世界観・和語中心の見出し／トークンと比べてややくだけて浮く。「〜を中心に」等の和語が馴染む。
- [ ] **C｜訴求（雰囲気）の弱まり**
  短縮により、旧文にあった体験価値（「季節のひと品とともに」「お庭を眺めながら」）が消え、「何を・どうぞ」の平坦な案内になった。導入文は店の雰囲気を一言添えると強い。

**方針**：係り先を「お食事」に限定して正確にし、和語でトーンを整え、お庭・季節などの雰囲気を一言添える（1〜2文）。

### 改善案（「／」は文の区切り。表示は1〜2行想定）

- [ ] **A（係り明確＋雰囲気／2文）**
  地元野菜を中心としたお食事に、甘味やお飲みもの。／お庭を眺めながら、ごゆっくりお楽しみください。
- [ ] **B（体験訴求・季節感／2文）**
  地元野菜を生かしたお食事や甘味、お飲みものを。／季節の彩りとともに、ごゆっくりお過ごしください。
- [ ] **C（現行に近い最小修正／1文）**
  地元野菜を中心に、お食事・甘味・お飲みものをご用意しています。ごゆっくりお楽しみください。

## カフェお品書き 説明文の短縮・差し替え（2026-07-25 起票 / 案提示済み・選定待ち）

対象: `index.html` カフェ「お品書き」3品の `hk-menu__item-desc`。
各品の案から1つ選定のうえ反映する（「／」は `<br>` に対応）。

### 元文の問題点

**共通**
- **1文が長く、列挙が読点でつながりすぎ**：メニューカードは「読む」より「一目で見る」もの。読点で要素を数珠つなぎにすると視線が止まらず、メインが掴みにくい。
- **カード表示幅に対して長い**：説明文は約14px・2行（合計40〜50字目安）が収まりよい。元文はいずれも超過し折り返しが増える。
- **修飾語の重ねすぎ・重複**：「地元野菜を使った」が御膳・弁当で重複、「〜を盛り込みました／お詰めしました」等の説明調が続き、訴求より説明が前面に出る。
- **表記ゆれ**：「甘味」と「甘み」など。短縮の過程で統一する。

**方針**：メインの魅力を1点に絞り、2文・2行以内に収め、表記を統一する。

### 品ごとの具体箇所

- [ ] **花かご御膳**
  - 元文:「竹籠に、もちもちの酵素玄米、地元野菜を使った彩り豊かなお惣菜、肉料理または魚料理を盛り込みました。お味噌汁とともに、心も体もほっとする、花かごおすすめの御膳です。」
  - 問題点: 前半が「竹籠に、A、B、C を盛り込みました」と3要素を一気に列挙して長い（約75字）／「もちもちの」「彩り豊かな」「心も体もほっとする」と形容が多層で売りが分散／後半も修飾続きで締めが重い。
  - A（素材重視）竹籠に、もちもち酵素玄米と地元野菜のお惣菜、肉または魚料理を彩りよく。／お味噌汁を添えた、花かご自慢の御膳です。
  - B（情感重視）もちもち酵素玄米に、地元野菜のお惣菜、肉または魚のひと品。／お味噌汁とともに、心も体もほっとする一膳です。
  - C（簡潔）酵素玄米と地元野菜のお惣菜、肉または魚料理を竹籠に。／お味噌汁を添えた、花かごおすすめの御膳です。
- [ ] **花かご弁当**
  - 元文:「花かご御膳をコンパクトに仕立てたお弁当です。地元野菜を使った手づくりのお惣菜と、肉料理または魚料理を、白ご飯とともにお詰めしました。店内でも、お持ち帰りでもお気軽にお楽しみいただけます。」
  - 問題点: 3文構成で情報過多（由来＋中身＋利用シーン、約90字で最長）で焦点がぼやける／「店内でも、お持ち帰りでも」はラベル「テイクアウト可」と重複／「地元野菜を使った」が御膳と重複。
  - A（由来を明示）花かご御膳をコンパクトに仕立てたお弁当。／地元野菜のお惣菜と肉または魚料理を、白ご飯とともにお詰めしました。
  - B（利用シーン重視）地元野菜の手づくり惣菜と肉または魚料理を、白ご飯とともに。／店内でも、お持ち帰りでも気軽に楽しめる一折です。
  - C（バランス型）御膳をコンパクトにしたお弁当です。／地元野菜のお惣菜と肉または魚料理を、白ご飯とともにお詰めしました。
- [ ] **かぼちゃプリン**
  - 元文:「かぼちゃ本来のやさしい甘味を生かし、なめらかに仕上げた手づくりプリンです。どこか懐かしく、ほっとする味わいをお楽しみください。」
  - 問題点: 3品では短めだが前半1文に「やさしい甘味」「なめらか」「手づくり」と要素が集中し一息が長い／「甘味」は「甘み」に寄せると味の意味が明確（甘味＝スイーツ区分とも読めるため）。
  - A（原文寄り）かぼちゃ本来のやさしい甘みを生かした、なめらかな手づくりプリン。／どこか懐かしく、ほっとする味わいです。
  - B（すっきり）かぼちゃのやさしい甘みを、なめらかに仕上げた手づくりプリン。／どこか懐かしい、ほっとするひと品です。
  - C（食感先出し）なめらかな口あたりの、手づくりかぼちゃプリン。／やさしい甘みと懐かしい味わいをお楽しみください。

- [ ] **B｜広告表現のリスク（要確認）**
  症状名（頭痛・肩こり・腰痛・ひざの痛み）の列挙＋「〜を図る整体療法」「自然治癒力を高めて…健康体に戻していきます」など、効果・治癒を思わせる表現。医業類似行為の広告や景表法・薬機法まわりで配慮が要る領域（※法的判断はできないため要確認）。効果を断定しない表現（「ととのえる」「サポートする」「お手伝い」等）に和らげ、症状は「ご相談ください」の誘導に留める方針を推奨。
- [ ] **C｜可読性（2文目が長すぎる）**
  2文目が「筋肉の癒着をとり／血液・リンパの流れを促進し／筋肉の緩和から骨格調整／関節可動域の回復／心的症状の緩和／運動機能の改善・向上を図る」と7要素超を読点で連結し1文が長大。専門用語（骨格調整・関節可動域・心的症状・運動機能）の羅列で一般来店者には難解。
- [ ] **D｜語の反復・トーン不一致**
  「緩和」の近接反復（筋肉の緩和・心的症状の緩和・心身を緩和）、「筋肉」の反復。クリニカルで硬く、サイト全体の和のやわらかいトーンと乖離。
- [ ] **E｜カード表示との相性**
  現行 `hk-clinic__copy` は2〜3行想定。原文は長く折り返しが増える。要点を絞って短縮する。

**方針**：症状の相談導線＋施術の要点＋やさしい印象の3点に絞り、効果の断定を避け、専門用語を平易化して短縮する。末尾の「※ 別経営・予約制です」フラグは残す。

### 改善案（「／」は文の区切り。実装時の改行は表示幅に合わせて調整）
