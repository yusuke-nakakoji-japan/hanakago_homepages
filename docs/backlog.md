## 利用規約.md 内容レビュー（2026-07-19 実施 / 未反映）

対象: `content/利用規約.md`。反映前レビューで検出した改善項目。
`【要確認】` は運用・好みの判断が必要なため、着手時に方針確認が必要。

### 優先度：高

- [ ] **B-1（矛盾）第5条2 ⇔ 第8条1｜排泄物の扱いが不整合**
  第5条2「速やかに処理し、お持ち帰りください」と第8条1「必ず処理してください」で、持ち帰り必須か施設内処理可か不明確。方針を一本化する。【要確認：持ち帰り / 施設処理】
- [ ] **C-1（論理）第2条2｜発情期を「健康状態」の括弧内から分離**
  「健康状態が良好であること（感染症・皮膚病・発情期は利用不可）」の発情期は健康の良否ではない。分離して記載（第6条2とも重複）。
- [ ] **C-2 / F-2①（係り受け）第6条7｜「許可なく」の係り先を明確化**
  現状:「許可なく他のお客様が写る写真・動画を撮影し、SNSその他インターネット上へ投稿する行為」
  → 案:「他のお客様が写った写真・動画を、許可なくSNS等インターネット上へ投稿する行為」
- [ ] **F-1①（主述ねじれ）第13条｜「みなす」の主体を当施設に**
  現状:「利用者は…同意したものとみなします」（主語と述語がねじれ）
  → 案:「お客様が当施設をご利用になった時点で、本規約に同意いただいたものとみなします。」

### 優先度：中

- [ ] **E-2（表記ゆれ）事業者の呼称統一**
  「当施設」（第1・9・12・13・14条）と「運営者」（第4・10・11条）が混在。「当施設」に統一推奨。※「スタッフ」は現場係員として残して可。【要確認：寄せる語】
- [ ] **E-3（表記ゆれ＋未定義）利用者の呼称統一・定義**
  「利用者」「お客様」「飼い主」が混在し、「利用者」は第1条で未定義。第1条で「以下「利用者」といいます」等を定義し統一。【要確認：寄せる語】
- [ ] **E-1（一貫性）箇条書き末尾の句点ルール統一**
  第4条・第6条（体言止め）は句点なし、他条は句点あり。特に第2条「〜こと。」と第4条「〜場合」が同種で不揃い。ルールを決めて統一（推奨: 体言止めは句点なし／完全文は句点あり）。

### 優先度：低

- [ ] **D-1（冗長）第1条｜「ご利用いただく」の近接反復**
  → 案:「本規約は、当施設をご利用いただくすべてのお客様に、安全かつ快適にお過ごしいただくための事項を定めるものです。」
- [ ] **D-2（冗長）第8条3｜「場合」の近接反復**
  → 案: 後半を「…ご負担いただくことがあります。」
- [ ] **E-4（表記ゆれ）犬の呼称統一**
  第5条のみ「愛犬」、他条は「犬」。統一推奨。
- [ ] **F-1②（無生物主語）第12条・第2条**
  第12条「本規約は…変更する」→「当施設は、必要に応じて本規約を変更することがあります。」
  第2条「ドッグランは…利用可能とします」→「ドッグランをご利用いただけるのは、次の条件を満たす犬に限ります。」
- [ ] **F-2②（冗長）第4条｜リード「場合は」と各項末尾「場合」の重複**
  各項末尾を「〜おそれがあるとき」等に、または末尾の「場合」を削って名詞句化。
