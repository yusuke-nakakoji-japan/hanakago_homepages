花かご 内部ツール ／ このページはお店の公開サイトには載りません

使い方（3ステップ）

  1. お知らせを追加・修正・並べ替え・削除します（上にあるほど新しく表示されます）。
  2. 「ホームページに適用」を押します。
  3. 1分ほど待って、サイトの画面を更新すると反映されます。

※ このページが外部に送信するのは「ホームページに適用」を押したときだけです。開いただけ・入力しただけでは何も送信されず、サイトも変わりません。

プレビュー

    実際のサイトと同じ表示です。見出しをクリックすると「＋」が「−」になり、本文が開きます（もう一度クリックで閉じます）。

    ホームページに反映

    編集が終わったら、下のボタンでホームページに反映します。初回だけトークンの準備が必要です（下の説明を参照）。

    ▶ 初回だけ必要：トークンの作り方（クリックで開く）
    1. GitHub → 右上アイコン → Settings → 左下 Developer settings → Fine-grained personal access tokens → Generate new token
    2. Repository access：「Only select repositories」→ hanakago_homepages を選択
    3. Permissions → Repository permissions → Contents を Read and write に設定
    4. 生成された github_pat_… をコピーし、下の「トークン」に貼り付け

    ※ トークンはこのリポジトリを書き換えられる鍵です。他人に渡さない・公開の場所に貼らないこと。上の権限（このリポジトリの Contents だけ）に絞れば、万一漏れても被害範囲を最小にできます。有効期限も短めがおすすめです。

    手動で反映する場合（任意・トークンを使わないとき）

    ▶ news.js の中身をコピー／ダウンロードする（クリックで開く）

    編集すると自動で更新されます。トークンを使わず手動でコミットしたいときだけ使用します（この内容を content/news.js に貼り付け、または置き換えてコミット）。
