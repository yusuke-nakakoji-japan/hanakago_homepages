# assets ディレクトリ運用ルール

サイトで使う素材（画像・装飾・アイコン等）の格納場所と命名規則をまとめる。
素材を追加するときは、この規則に従って配置すること。

## ディレクトリ構成

```
assets/
├── images/        写真・画像素材（用途ごとにサブフォルダで分ける）
│   ├── logo/      ロゴ
│   ├── hero/      ヒーロー（メインビジュアル）
│   ├── menu/      メニュー写真
│   ├── dog/       ドッグラン関連
│   └── gallery/   ギャラリー（順序ありのため連番プレフィックス）
├── patterns/      和柄など装飾用の SVG（背景パターン等）
└── icons/         favicon / apple-touch-icon など
```

## 命名規則

- 英小文字 + ハイフン区切り（ケバブケース）。全角・空白は使わない。
  例: `terms-of-service`, `hero-spring`
- **順序が意味を持つセット**（ギャラリー等）は `01-`, `02-` の連番プレフィックスを付ける。
  例: `01-komorebi.jpeg`
- ファイル名から中身が推測できる名前にする。

## 素材を追加するとき

1. **画像を追加** → 用途に合う `images/<用途>/` へ置く。該当フォルダがなければ新設してよい
   （例: お知らせ用画像なら `images/news/`）。
2. **背景・装飾の SVG を追加** → `patterns/` へ置く。
3. **favicon 等** → `icons/` へ置く。
4. 追加後、`index.html`（および必要なら `styles/kit.css`）から相対パスで参照する。
   - `index.html` から: `assets/images/...`
   - `styles/kit.css` から: `../assets/patterns/...`（css は `styles/` にあるため `../` が必要）

## まだ用意していない素材の置き場所（必要になったら新設）

- `images/og/` … OGP / SNS シェア用画像
- `documents/` … PDF 等のダウンロード配布物（利用規約の同意書などを配布する場合）
  - ※ 利用規約・プライバシーポリシー等の**文章は `index.html` に直接記載**する方針のため、
    文章自体はここには置かない。あくまで「ダウンロードさせるファイル」を置く場所。
